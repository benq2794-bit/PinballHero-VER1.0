# 彈射之境｜資料夾指南

## 遊戲執行與部署

- `index.html`：遊戲入口。
- `asset/`：遊戲會載入的程式、圖片、音效與背景。請保留整個資料夾。
- `scripts/build-release.cjs`：建置到 `dist/`（Cloudflare Pages 輸出目錄，會產生 `_headers` 快取規則）。

要直接開遊戲，開啟 `index.html`。移除 `asset/` 裡的檔案可能會讓遊戲缺圖、缺音效或無法啟動。

## 遊戲設計與參考資料

- `design-reference/`：來源圖片、素材候選與素材預覽頁。它們不會被遊戲主程式載入，但保留作為設計備份。
- `previews/`：技能、狀態效果與介面概念預覽。
- `docs/`：系統架構與歷史盤點文件。

## 開發與測試資料

- `tests/`：遊戲邏輯與瀏覽器檢查程式。
- `dev-tools/`：素材處理輔助工具。
- `dev-artifacts/`：瀏覽器輸出記錄與暫存資料；不是遊戲素材。

若只想保留可執行遊戲，請至少保留 `index.html`、完整的 `asset/`。其餘資料夾依上方說明區分；參考圖與預覽先留著，確認不再需要再自行移除。
