# 版本更新補償

設定檔：`asset/update-compensation.js`。

- 批次清單為 `UPDATE_COMPENSATION_BATCHES`，目前明確建立 `update-compensation-20261108-01`。
- 需要新的補償時，在清單尾端追加 `{ id:'全新且從未使用的固定 ID', name:'顯示名稱' }`，並保留舊項目。不可更改或重用既有 ID。
- 不從版本號、部署識別碼、登入日期或執行時間自動產生批次。單純部署不增加補償。
- 每批固定：虹彩石100、金幣10000、限定招募單抽券1、經驗水晶100、高階經驗水晶10；不含體力，不受活動加倍影響。
- 既有 JSON 存檔新增相容欄位 `updateCompensationClaims`，保留所有歷史批次 ID，即使該批次已從展示清單移除也不抹除領取紀錄。
- 玩家手動領取，資源與領取 ID 於同一存檔寫入。寫入失敗會還原。達資源上限時保留未領取資格，不截斷獎勵。
- 沿用活動領獎的分頁鎖與舊分頁檢查；登入帳號領取前也讀取現有雲端存檔比對領取紀錄，無法確認時不發獎。
- 雲端保存沿用既有整份 JSON 存檔同步；不新增伺服器原子領獎服務。同帳號兩裝置完全同時領取的伺服器原子保證不在現有架構能力內。
